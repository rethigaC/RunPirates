# 🏴‍☠️ RUN PIRATE RUN

**RUN PIRATE RUN** is a real-time 2D adventure game built using **Python and Pygame**, designed to showcase interactive gameplay mechanics, progressive difficulty, timed quiz triggers, and efficient asset-based resource loading. This project is structured for easy execution locally and in notebook demo environments.

---

## ✨ Game Highlights

- 🧠 **Randomized obstacle generation** for unpredictable gameplay
- 📈 **Adaptive speed scaling** to increase difficulty over time
- ⏱️ **Timed quiz triggers** based on game speed intervals
- ⛔ **Collision detection** with Game-Over state handling
- ⏸️ **Pause and Resume system** integrated into the game loop
- 📂 **Modular asset loading** using relative paths for GitHub compatibility
- ▶️ **Notebook execution support** to trigger the game via Jupyter/Binder
- 🏁 **Progressive difficulty increments** every 2 obstacle crossings
- 🖼️ **Image-based quiz display system**
